Notifikasi tidak muncul di Xiaomi / HyperOS?

1. Pengaturan → Notifikasi → Chrome (dan aplikasi Semester 5 kalau sudah dipasang): izinkan notifikasi.
2. Pengaturan → Aplikasi → Chrome → Hemat baterai: pilih Tanpa batasan; aktifkan Mulai otomatis.
3. Matikan mode Jangan Ganggu (ikon bulan di bilah status).
4. Pesan forum tidak muncul sebagai notifikasi kalau aplikasi sedang terbuka di layar; cukup tampil di dalam aplikasi.

Pasang ke layar utama HP supaya terbuka seperti aplikasi. iPhone: buka lewat Safari, ketuk Bagikan, lalu Tambahkan ke Layar Utama (perlu iOS 16.4 atau lebih baru untuk notifikasi).
